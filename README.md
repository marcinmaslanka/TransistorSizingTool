## Quick Start Guide

Follow these steps to size a transistor using the web application:

1. Open the application in your web browser:
   - https://transistorsizingtool.onrender.com/

2. Enter the desired amplifier specifications in the input tables.

3. Click **Calculate** to start the sizing process.

4. Select a suitable design point from the **Design Space** plot.

5. Read the calculated transistor parameters (**W**, **L**, and **ID**) from the results table.
